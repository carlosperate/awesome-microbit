# MkDocs Theme

Based on the default MkDocs theme, with custom CSS overrides in `extend.css`.

Updated to commit [2862536793b3c67d9d83c33e0dd6d50a791928f8](https://github.com/mkdocs/mkdocs/tree/2862536793b3c67d9d83c33e0dd6d50a791928f8/mkdocs/themes/mkdocs)
from 20th October 2025.

### Custom Modifications Since Import
- **`css/extend.css`**: Added a sticky Table of Contents sidebar with internal scrolling, hidden scrollbar until hover, and active state highlights for the active scrollspy element (`.nav-link.active`).
- **`js/base.js`**: Replaced Bootstrap's native ScrollSpy with a custom implementation to properly track layout hashes matching emojis inside IDs (since MkDocs encodes emojis in anchors).
- **`base.html`**: Updated the repo link in the navbar to show only the icon (GitHub, GitLab, or Bitbucket) without text.
- **`css/awesome-microbit.css`**: Awesome micro:bit colours and details for the awesome_list hook's cards, on top of the hook's default layout, for light and dark mode. Each section of a list page gets its own hue, and index lists use two columns where there is room.
- **`js/awesome-microbit.js`**: Sets each card picture as its own blurred backdrop once it loads, gives the cards and Contents tiles the pointer's position for their hover shadow, and switches a card to its favicon when its image fails to load in the browser.
- **`base.html`**: Loads `css/awesome-microbit.css` and `js/awesome-microbit.js` in the `<head>`, after `extra_css` so the CSS overrides the hook's default card styles.
- **`content.html`**: On pages with awesome lists, wraps each `h2` section in a `<section class="awesome-section">` with its number in `--awesome-section`, used for the section colours.
- **`css/extend.css`**: Restored Bootstrap's left gutter on the main container below 768px, where the sidebar is hidden, so the content no longer touches the left edge on phones.
- **`base.html`**: Below 768px the sidebar is hidden and its table of contents is at the end of the navbar menu instead. The navbar has no "Home" entry, as the site name links there, and the repository icon gets a label in the collapsed menu, like the theme toggle.
- **`js/awesome-microbit.js`**: Closes the navbar menu before jumping to an entry of its table of contents, as the open menu pushes the page down.
- **`js/base.js`**: `applyTopPadding()` also sets the sidebar's height from the navbar's, so it reaches the bottom of the screen when the navbar is collapsed.
- **`css/extend.css`**: Heading spacing: more space above `h2` than `h3`, an `h3` that scales with the screen width and has a regular weight, a responsive `h1` that fits on one line on phones and tablets, and space between headings and the navbar when jumping to them. The sidebar fills its column on pages with a short table of contents, its wrapped entries have tighter lines, and hovering an entry changes its colour instead of making it bold, which re-wrapped long entries. Inline code has rounded corners and the content more space at the bottom.
- **`css/awesome-microbit.css`**: Code in card titles (the Community handles) drops its box and link colour, and index lists sit as close to their heading as cards.
- **`css/extend.css`**: The site name in the navbar stays white and glows in the menu's hover purple on hover and keyboard focus, instead of turning the dark link hover colour, which was hard to read on the navbar.
- **`css/extend.css`**: Dark mode for the whole page. The colours the page uses are named tokens (page, content, rules, links, sidebar links, footer, the `h1` gradient), which dark mode sets to purple-tinted darks along with Bootstrap's own surfaces and text. Pictures on their own, like the README logo, get rounded corners and are softened in dark mode, as they are white.
- **`base.html`** and **`img/social-card.png`**: Open Graph and Twitter card tags for link previews on social media and chat apps, with a 1200×630 card of the logo, the tagline and the section colours. The homepage's tags take the description from `site_description`, like its meta description, and the image tags (and the large card type) need `site_url` for the absolute image URL.
- **`content.html`**, **`contents-tiles.html`** and **`css/awesome-microbit.css`**: The section named by the `contents_tiles` theme option (a heading anchor) shows a colour tile for each section with entries instead of its list: the section's emoji, name and number of entries, in the section's colour. The tiles are built from the page's headings (`base.html` collects them once for the tiles and the phone menu), so they link to the MkDocs ids and follow the sidebar's names, and use the cards' colour tokens. Four columns on large desktops down to two on phones, where the emoji sits above the name. `hooks/contents_tiles.py` warns during the build if that section holds anything besides its list, as the tiles leave it out.
- **`css/extend.css`**, **`js/awesome-microbit.js`** and **`js/base.js`**: The sidebar's current section has a thick bar over the sidebar's border and its text in the section's colour (the site's purple on pages and sections without lists), which `js/awesome-microbit.js` copies to each entry from its section. Hovering an entry gives it a rounded purple background instead of a thicker border, so the text never moves. The scrollspy no longer marks parent entries, so only the current entry is styled.
- **`js/darkmode.js`**: Turns transitions off for a frame while switching theme, as every link and card would otherwise animate to its new colour.
- **`toc.html`**, **`css/extend.css`** and **`js/base.js`**: When the current section changes, its bar and a rounded background tinted in its colour glide to the new entry and blend into its colour, while the text fades to it. CSS anchor positioning moves them, using two elements in `toc.html` (Safari stops animating pseudo-elements when the hue changes), and the scrollspy gives the sidebar the current entry's hue. Firefox moves them without the animation, browsers without anchor positioning keep the bar on the entry, and reduced motion turns the glide off.
- **`base.html`** and **`js/darkmode.js`**: A `theme-color` meta tag gives the browser's own bar on phones the navbar's colour over the page, and `js/darkmode.js` switches it to the dark mode colour with the theme.
- **`content.html`**, **`css/awesome-microbit.css`**, **`js/awesome-microbit.js`** and **`js/base.js`**: On list pages, a bar under the navbar names the current section with its number of entries, in the section's colour (the cards' tokens), and a line along its bottom shows how far down the page that is. It appears from the first section on, and the scrollspy tells it the current section with a `scrollspy` event. On phones it opens the menu at the current section, which the menu highlights; elsewhere it jumps to the section's start. `applyTopPadding()` adds its height to the scroll padding, so jumps land below it, and the scrollspy's line now follows the scroll padding instead of a fixed 100px.
- **`css/extend.css`**: The sidebar's background and border are on its scrolling element (the border as an inset shadow, so the current section's bar still covers it), as the overscroll bounce in Chrome and Safari moves the entries and showed the white content background behind them.
- **`img/favicon.ico`**: The favicon is the micro:bit with the glasses from the README's logo, on a transparent background, at 16, 32, 48 and 64px, instead of the MkDocs one.
- **`css/awesome-microbit.css`** and **`js/awesome-microbit.js`**: The hook's `shelf` style, used for the Books covers, puts them on glass shelves tinted in the section's colour, with the foot of each cover reflected in the glass. The reflection is the cover picture flipped in a pseudo-element (from the `--awesome-image` the script already sets), as `-webkit-box-reflect` doesn't work in Firefox. The shelves are the list's background, repeating with the rows, which all have the same height. A cover lifts on hover or keyboard focus and shows the book's details 20px above it, or below it when the navbar and section bar would cover them. On touch screens the first tap on a cover shows its details, and a tap on the details or a second tap on the cover opens the book. `js/awesome-microbit.js` spreads the covers evenly over the rows (5, 5, 5, 4 rather than 6, 6, 6, 1) with margins on each row's first and last cover, and lines those two covers' details up with them so they stay inside the list. Phones get smaller covers. A book without a cover image yet gets a plain one in the section's colour with its favicon.
- **`css/awesome-microbit.css`** and **`js/awesome-microbit.js`**: On hover or keyboard focus, cards and Contents tiles nudge up and left over a hard shadow in their section's colour, brighter where the pointer is (cards 2px over 3px, tiles 1px over 2px), and press down on click. This replaces the picture glow that followed the pointer. The shadow is a layer behind the card, as `box-shadow` can't take a gradient, and the card moves with `top` and `left`, as a transform would put that layer in front of its background. Only on devices that can hover; index rows keep their background tint.
